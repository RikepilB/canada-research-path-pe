# Datos editables

La web lee estos archivos directamente:

- `opportunities.json`: programas, becas y rutas de investigación.
- `stories.json`: casos públicos de beneficiarios con su fuente.
- `contacts.json`: oficinas y contactos institucionales públicos.

## Editar desde GitHub

1. Abre el archivo.
2. Pulsa el icono del lápiz.
3. Cambia solo los campos necesarios.
4. Actualiza `verifiedAt` cuando corresponda.
5. Propón el cambio mediante un pull request.

Mantén JSON válido: comillas dobles, coma entre elementos y ninguna coma después del último elemento. Toda fecha, monto, requisito o persona debe incluir una fuente pública. No añadas teléfonos, correos o datos personales que la persona no haya publicado con una función institucional.
