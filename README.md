# Canada Research Path PE

Guía pública en español sobre becas, movilidad y colaboración científica entre Perú y Canadá.

La web reúne programas federales y universitarios, rutas con supervisor, recursos peruanos y una selección de oportunidades de la hoja pública de InVivoLab. Cada entrada conserva su fuente y fecha de corte para que una convocatoria vencida no parezca vigente.

## Ver la guía

Abre `index.html` en cualquier navegador. No requiere instalación, compilación ni servicios externos.

## Alcance

- Becas y pasantías para pregrado, posgrado y posdoctorado.
- ELAP, SICS, Mitacs, CGRS-D, Canada Impact+, premios universitarios y PROCIENCIA.
- Oficinas y redes que reciben investigadores visitantes.
- Proceso práctico para encontrar un supervisor canadiense.
- Mecánica migratoria básica para estancias cortas.

## Fuentes

El corte editorial actual es el 7 de septiembre de 2026. Las fechas cambian en cada ciclo: usa esta web para orientarte y confirma la convocatoria en el enlace oficial antes de postular.

La selección de la hoja de oportunidades se atribuye a [InVivoLab](https://invivolab.org/) y no redistribuye el archivo completo.
