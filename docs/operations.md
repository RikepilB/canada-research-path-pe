# Operación

GitHub Pages publica la rama `main`. Cada cambio debe pasar las pruebas, la validación del catálogo y la construcción del HTML autónomo.

Para revertir una publicación, revierte el commit causante mediante un pull request y espera la nueva publicación de Pages. La web no usa cuentas, formularios, analítica, cookies ni almacenamiento de datos personales.
